# 画册拼版台 · Imposition Studio

浏览器内使用的**骑马钉画册拼版、折叠预演与多订单合版（gang run）工具**。印前制作人员在送印前即可直观核对每张印张正反面的页码位置、朝向、装订边、裁切线、出血区，以及折叠成册后的真实页序；印厂夜班还能把**多本小批量画册合在同一张母版大纸上**：系统按纸纹、咬口、禁印区、双面镜像与直线刀路可分离性排布多个订单的书帖，给出用纸、超印、换版成本与废纸率。客户临时增删页面、更换翻面方式或锁定某帖位置时，错位、倒页、背面套不准、裁刀切穿另一订单等问题不用等到上机才发现。

纯前端实现：React 19 + TypeScript + Vite，数据保存在浏览器 `localStorage`，无需后端。

## 功能

### 单书拼版（原有）

- **首屏内置 16 页产品手册**（4 张印张），打开即用。
- **左侧 · 页面顺序**：拖动排序、增删页面、编辑标题/源稿页码/出血，标记"来稿倒置"；页数不是 4 的倍数时**自动在封底之前补白**。
- **中间 · 印张拼版**：正/反面页码、摆放朝向、装订边/折线、裁切线（含角线）、出血区与出血值、装订侧/开口侧；**长边翻转 ↔ 短边翻转**一键切换，短边翻面背面整版旋转 180°。
- **右侧 · 折叠预演**：成书逐页翻看、逐张 3D 翻面/对折、问题清单（跳号、重复、倒置、出血不足、补白）。

### 多单合版（新增）

顶部切换到 **多单合版** 工作台，内置三个不同尺寸与印数的订单示例（A4 文旅画册 300 册、200×260 艺术展刊 120 册、140×210 产品小册 360 册）。

- **订单管理**：成品宽/高、书帖数、印数、纸张品种、纸纹（顺纹/横纹）、允许超印、交期、是否允许旋转 90°、书帖是否已通过单书拼版验证。
- **母版与上机设置**：在大度对开 889×597 / 正度对开 787×546 / A2+ 640×460 之间选择母版纸；配置**咬口（叼口）位置与宽度**、自定义**禁印区**（可跟随翻面镜像到背面）；选择印刷方式：
  - **自翻版·左右翻（work-and-turn）**：一套印版，背面横向镜像，机台咬口边不变；
  - **自翻版·上下翻（work-and-tumble）**：背面整版旋转 180°（x、y 同时镜像）；
  - **正反版（work-and-back）**：正反两套独立印版分别对位，换版费 ×2。
  - 两种优化策略：**最少超印** / **最少换版**。
- **生产单元 = 正反绑定的一个书帖**：每个已验证订单的每帖摊平为 2×成品宽的印面；摆放时同步验证正面与翻面后背面的位置。
- **母版正反面视图（SVG）**：
  - 订单身份色与订单名/帖号、书帖中缝折线；
  - 母版**纸纹**方向底纹、咬口红区、禁印区斜纹；
  - **裁切线**：按直线刀序绘制贯穿刀路；
  - 正面/背面并列，背面按所选印刷方式做真实镜像（短边翻内容旋转 180°）；
  - **拖动书帖即人工锁定**到整数毫米坐标，其余单元自动围绕重排，锁定只固定位置、不豁免任何物理校验；可解锁交回自动排版。
- **计划指标**：总母版用纸张数、套版（换版）数、总超印、**废纸率**、纸钱、换版费与合计；逐订单进度条展示**印数满足**（计划册数/需求/允许超印/参与的套版）；逐版列出直线裁切刀序。
- **方案对比基线**：把任意时刻的计划存为基线，之后所有调整都与基线对比纸张数、套版、超印、纸钱、换版费、合计与废纸率（绿降红升）。
- **撤销/重做**：订单、母版、咬口、禁印区、策略、锁定的修改全部可撤销（拖拽一个手势只产生一个历史条目）；**工作区、锁定、基线、历史均保存在浏览器本地**，刷新继续。

## 合版模型

**坐标**：母版正面左上角为原点（mm，x 向右、y 向下），母版规范化为长边水平。正面矩形 `R` 映到背面直视位置：

| 印刷方式 | 背面矩形 |
| --- | --- |
| work-and-turn（长边左右翻） | `(W−x−w, y)`，仅横向镜像 |
| work-and-tumble（短边上下翻） | `(W−x−w, H−y−h)`，整版 180° |
| work-and-back（正反版） | `(x, y)`，两套版独立对位 |

三种方式都满足**往返一致**（映两次回到原位）。咬口在左右翻时咬住的顶/底边不变、上下翻换到对侧、正反版同位；禁印区可选择是否跟随翻面。

**纸纹**：订单纸纹相对成品长边、母版纸纹相对母版长边；成品长边必须与母版纤维方向的平行关系匹配两者纸纹（相同→平行，不同→垂直），需要垂直且订单禁止旋转则直接拒绝，而不是悄悄错纹。

**数量倍数**：逐版封版，版次取版上各订单剩余容量的最小值；覆盖订单全部书帖的版允许印到 `run + allowOvers`，只覆盖部分书帖的版最多印到 `run`（缺帖版印超的部分无法成套）。同一书帖可跨版分摊印数（如 120 + 180 = 300），订单册数按各书帖所得印次的最小值配套。

**直线裁切可分离（guillotine）**：每放入一个单元都重新判定整版是否可被"一刀贯穿当前料块、且刀路不压任何单元"的序列切成单件。枚举单元边界作为候选刀线（先竖后横、坐标升序），递归二分；风车形互锁等无贯穿缝的**嵌套排布即使零重叠也会被拒绝**——不能用不可分离的嵌套换取虚假高利用率。最终刀序随计划返回并绘制在母版上。

**确定性优化**：底左（bottom-left）装箱，候选点 = 料块原点与已占矩形边的笛卡尔积，按 y 再 x 排序；订单优先级、朝向、坐标、开版顺序全部固定，不使用随机数或无序迭代——同一输入（含锁定）逐字段产出同一计划，撤销与基线对比都可复现。

示例数据（大度对开、12mm 咬口、自翻左右翻、最少超印）典型结果：5 套版、840 张母版纸、废纸率约 35%，三订单全部满足，小册跨版分摊并受控超印 40 册（恰为其允许上限）。

## 运行方式

要求 Node.js 18+（开发环境使用 Node 22 验证）。

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器，默认 http://localhost:5173
npm test           # 运行全部测试（Vitest，一次性）
npm run test:watch # 监听模式
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建
```

- `src/imposition.test.ts`（25）单书核心：补白、骑马钉页码配对、长边/短边翻转几何、折叠后阅读顺序与朝向、问题检测。

  - **纸纹**：顺纹/横纹 × 竖版/横版 × 是否旋转的真值表、三个示例订单的必需旋转、旋转后版面宽高交换；

  - **直线裁切可分离**：并排一刀、2×2 网格切到单件、风车互锁被拒、同组共刀、越界拒绝；

  - **人工锁定**：锁定坐标保持、压咬口/互撞/违反纸纹被拒、其余单元围绕重排且印数仍满足；
  - **确定性**：同输入（含锁定/禁印区/印刷方式）逐字段一致、打乱订单数组不影响结果。

## 说明与限制

- 出血阈值固定为 3mm（`src/lib/imposition.ts` 的 `MIN_BLEED_MM`）；合版单元间留缝固定为 3mm（`CELL_GAP_MM`，出血 + 刀路余量）。
- 缩略图以色块 + 标题示意客户稿件，不解析真实 PDF/图片。
- 单书数据键 `imposition-studio:v1`，合版数据键 `imposition-studio:gang-v1`，视图偏好键 `imposition-studio:view`；两个"重置"按钮分别恢复各自内置示例。
- 合版为 guillotine 直线刀 + 底左确定性启发式，不追求全局最优装箱；它保证的是**物理可上机**（无碰撞、纸纹正确、背面对位、可直刀分离、印数账实相符），而不是极限利用率。
