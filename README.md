# 画册拼版台 · Imposition Studio

浏览器内的**骑马钉画册拼版工具**，含两个工作区：

1. **单本拼版**：送印前直观核对单本书每张印张正反面的页码位置、朝向、装订边、裁切线、出血区，以及折叠成册后的真实页序；
2. **多订单合版（gang run）**：印厂夜班把几本小批量画册合在同一张大纸上印。可建立多个订单（成品尺寸、书帖数、印数、纸张/纸纹、允许超印、交期），选择母版纸、咬口、禁印区与印刷方式；系统把每个**已验证书帖**当作正反绑定的生产单元，生成无重叠、符合纸纹与咬口的排布，校验背面镜像套准、数量倍数与 **guillotine 直线裁切可分离性**，并支持锁定人工放置后重新优化其余单元、比较两套计划的纸张/超印/换版成本。

纯前端实现：React 19 + TypeScript + Vite，数据保存在浏览器 `localStorage`，无需后端。顶部用「单本拼版 / 多订单合版」切换，两个工作区的状态分别持久化。

## 功能

### 单本拼版

- **首屏内置 16 页产品手册**（4 张印张），打开即用。
- **左侧 · 页面顺序**
  - 按阅读顺序排列的页面缩略图；
  - 鼠标拖动调整顺序，支持增加 / 删除页面，双击标题或点 ✎ 可编辑标题、源稿页码、出血值，可标记"来稿倒置"；
  - 页数不是 4 的倍数时，**自动在封底之前补入空白页**（封底始终是全书最后一页）。
- **中间 · 印张拼版**
  - 按纸张层级（最外层 → 最内层）展示每张纸的**正面 / 背面**；
  - 明确标注：阅读页码、源稿页码、**摆放朝向（正立 / 180°）**、**装订边 / 折线**、**裁切线（含角线）**、**出血区及出血值**、装订侧 / 开口侧；
  - **长边翻转 ↔ 短边翻转（tumble）一键切换**：背面不仅改标签——短边翻面时背面左右槽位互换、整版旋转 180°，几何排列立即重排。
- **右侧 · 折叠预演**
  - 模拟成册后的逐页翻看（封面 → 跨页 → 封底）；
  - **逐张折叠演示**：每张纸可 3D 翻面（长边左右翻 / 短边上下翻）、沿装订边对折，并列出该张折叠后的阅读顺序；
  - **自动检查**：缺页（源稿跳号）、重复页（源稿页号重复）、倒置（来稿倒放或拼版旋转错误）、出血不足（< 3mm）、自动补白；点击问题可跳转到对应页。
- **本地持久化**：所有编辑、翻面方式、预演翻页位置、选中的印张都保存在浏览器本地，刷新后继续。

### 多订单合版

- **订单管理（左栏）**：建立多个订单，配置**成品尺寸、书帖数量、印数、纸张、纸纹（顺纹/横纹）、允许超印、交期**与身份颜色；只有**已验证**订单（稿件/页码校验通过）才纳入合版，草稿订单被排除并提示。新建订单即为草稿，点「标记已验证」上机。
- **母版与上机设置**：内置大度对开/正度对开/A2/A1 预设，可自定义母版尺寸；配置**咬口所在边与宽度、矩形禁印区、印刷方式（双面/单面）、翻面方式（长边/短边）、印数步进、是否允许旋转 90°**。
- **生产单元 = 已验证书帖**：每个书帖展开为 `2×成品宽 × 成品高` 的矩形，**正反面绑定**——只摆正面，背面由翻面方式镜像自动确定，背面位置无法单独挪动。
- **确定性优化排布（中栏）**：
  - SVG 同时绘制**母版正面与背面**：订单颜色/身份、书帖序号、**纸纹方向线**、摆放旋转角、咬口条带、禁印区，以及**带编号的贯穿直线裁切线**（编号即下刀顺序）；
  - 装箱采用确定性 **guillotine 自由矩形切分**：自由矩形的每次切分本身就是一条贯穿刀路，因此排布**天然可直线分离**——绝不以 pinwheel 风车式不可分离嵌套换取虚假高利用率；
  - 约束包括：正面/背面分别**无碰撞**、不出界、不侵咬口/禁印区（背面视角这些区域随翻面镜像）、**纸纹一致**（不同纹向默认分版；开启允许旋转后少数派可旋转 90° 校正纹向）；
  - 一张母版摆不下自动增加印版套数；成品计划再经独立 `validatePlan` 复核（镜像套准、双面碰撞、咬口禁印、可分离性）。
- **数量倍数与超印**：同纸同纹订单按印数贪心成组，**共享一套印次**（印数向上取整到印刷步进），小订单由此获得超印册数，但分组时受各自 `maxOvershoot` 约束——会超限就另开一版，不强行合版。
- **锁定与重新优化**：在正面**点击色块锁定/解锁，锁定后可拖动**到人工位置；锁定项作为固定障碍，其余单元绕开它们重新排布，侵入咬口/越界的非法锁定会被忽略。支持 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z 撤销重做。
- **指标与比较（右栏）**：印版套数（=换版次数）、耗用母版张数、**废纸率**、总超印、纸张+超印+换版三项成本；每个订单的**印数满足进度条**（含超印/缺口）与告警。可把当前计划**存为基线 A**，随后修改并与当前 B 并排比较母版张数、超印、换版次数与总成本差额。
- **内置三个不同尺寸与印数的样例订单**（500/480/460 册），同纸同纹合为一套 ×500 张，直观展示 20/40 册超印与 50.4% 废纸率。
- **本地持久化**：订单、母版、人工锁定、比较基线以及撤销/重做历史均保存在浏览器本地（键名 `imposition-studio:gang:v1`），刷新后继续。

## 拼版模型

骑马钉一张纸对折产生 4 个书页，多张纸从外向内套叠。成书共 N 页（N 为 4 的倍数）时，第 k 张纸（k 从 0 起）：

| 翻面方式 | 正面（直视印刷面） | 背面 |
| --- | --- | --- |
| 长边翻转 | `[ N-2k ｜ 2k+1 ]`，槽位正立 | `[ 2k+2 ｜ N-2k-1 ]`，槽位正立 |
| 短边翻转 | 同正面 | `[ N-2k-1 ｜ 2k+2 ]`，两个槽位均旋转 180° |

以 16 页为例：`[16｜1]/[2｜15]`、`[14｜3]/[4｜13]`、`[12｜5]/[6｜11]`、`[10｜7]/[8｜9]`。
短边翻面时背面整版旋转 180°，上下翻页后旋转被几何抵消，读者看到的仍是正立页——这一结论在折叠顺序测试中校验。

### 多订单合版模型

- **正反镜像**：长边翻转背面 `x' = W − x − w`；短边翻转 `y' = H − y − h`；朝向 `0↔180、90↔270`。镜像为自反变换，镜像两次严格回到原位。
- **纸纹**：`0°/180°` 摆放不改纹向，`90°/270°` 把纹向转 90°；不同纸张绝不共版，不同纹向默认分版。
- **咬口/禁印区**：先扣除咬口得到可印区，禁印区在自由矩形中挖空；背面视角下这些物理区域按翻面轴镜像，因此左右咬口在长边翻面后落到对侧。
- **数量分组**：`runLength = 向上取整(组内最大印数 / 步进) × 步进`；小订单加入条件 `runLength − quantity ≤ maxOvershoot`。
- **可裁切性**：`guillotineCuts()` 递归寻找把矩形集合分成两个非空子集的贯穿刀路；pinwheel 风车等互锁布局不存在这样的刀路，判定为不可分离（测试中以经典 5 矩形 pinwheel 与 4 矩形十字互锁为反例）。
- **确定性**：装箱单元按面积降序、id 决胜；落点按残留面积→y→x→旋转角取最小；相同输入逐字节产生相同计划。

## 运行方式

要求 Node.js 18+（开发环境使用 Node 22 验证）。

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器，默认 http://localhost:5173
npm test           # 运行全部测试（Vitest，一次性）
npm run test:watch # 监听模式
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建
```

## 测试

`src/imposition.test.ts` 针对单本拼版纯函数核心（Vitest / Node 环境）：

- **补白**：13/14/15/17 页补齐到 4 的倍数，空白页位于封底之前，封底仍在最后；空列表安全处理；
- **页码配对**：16 页标准骑马钉配对 `[16,1]/[2,15] …`，4/8/12/16/20 页下每个阅读位置恰好出现一次，非 4 倍数输入抛错；
- **双面翻转**：长边背面正立；短边背面槽位左右互换且全部旋转 180°（不只是文字标签）；两种翻面正面一致、背面页面集合相同；
- **折叠后阅读顺序**：严格 1..N，两种翻面下正常来稿折叠后全部正立，来稿自身倒置时标记 180°，补白页正立出现；
- **问题检测**：重复源页号、跳号缺页、出血不足、补白提示。

`src/gangrun.test.ts` 针对多订单合版核心（54 个用例）：

- **双面映射**：长边 x 镜像 / 短边 y 镜像、镜像两次还原、宽高不变、朝向 0↔180、90↔270、单面印刷不镜像；
- **碰撞**：相交检测、共边共线（刀路贴合）不算重叠；
- **纸纹/旋转/咬口/禁印区**：0/180 不改纹向、90/270 改纹向、默认禁 90°、四边咬口可印区扣除、背面咬口随翻面镜像；
- **数量展开与倍数**：书帖展开宽 = 2×成品宽、草稿不展开、小订单在超印限内搭版/超限分版、异纸异纹分版、步进向上取整、允许旋转时异纹并入；
- **裁切可分离**：单块、并排 1 刀、2×2 网格 3 刀、L 形可分离，**pinwheel 与十字互锁判为不可分离**；
- **确定性装箱**：无重叠不侵咬口、摆不下进 unplaced、避开禁印区、重复运行与输入顺序无关、锁定被尊重且其余绕开、非法锁定被忽略、异纹 90° 摆入；
- **端到端计划**：双面镜像套准、短边翻转套准、印数满足与超印、超限分版印数准确、摆不下报短缺、废纸率区间、草稿提示、篡改背面被 `validatePlan` 捕获、计划确定性、锁定后重排仍合法；
- **成本与比较**：三项成本求和、两计划张数/超印/换版差额与更便宜方、相同计划持平。

`src/App.smoke.test.tsx`（jsdom）挂载真实组件树，验证单本拼版首屏 16 页、短边翻面 180° 重排、删除补白与 `localStorage` 持久化、刷新恢复。

`src/GangWorkspace.smoke.test.tsx`（jsdom）验证合版工作区：三视图订单与正反面 SVG/指标渲染、三订单单套 ×500 张与超印 20/40、正反面身份色块与裁切线、订单编辑持久化与刷新恢复、撤销/重做、基线 A/B 比较、草稿订单排除。

共 90 个用例。

## 说明与限制

- 出血阈值固定为 3mm（`src/lib/imposition.ts` 的 `MIN_BLEED_MM`）；
- 缩略图以色块 + 标题示意客户稿件，不解析真实 PDF/图片；
- 合版尺寸以毫米为单位做矩形几何，未模拟印刷伸缩/咬口拖梢渐变；裁切线为 guillotine 贯穿直刀，不含异形模切；
- 成本权重（每张母版、每册超印、每次换版）在 `DEFAULT_COST_WEIGHTS` 中给出默认值，可按实际工价调整；
- 数据仅存于当前浏览器：单本键名 `imposition-studio:v1`，合版键名 `imposition-studio:gang:v1`，各自提供「重置/恢复内置样例」。
